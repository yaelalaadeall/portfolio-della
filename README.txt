DELLA TRI WAHYUNINGRUM - PORTFOLIO

1. Ekstrak folder ZIP.
2. Buka folder Della_Pastel_Portfolio di Visual Studio Code.
3. Letakkan foto profil di assets/foto-della.jpg.
4. Letakkan CV PDF di assets/CV-Della.pdf.
5. Edit placeholder email, sosial media, periode sekolah, serta tautan project di index.html.
6. Jalankan index.html dengan ekstensi Live Server.

Semua HTML, CSS, dan JavaScript ada di satu file index.html. Tidak memakai backend/database.
